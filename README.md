# Starlight Front Desk
1. Supabase SQL Editor: run sql/01_schema.sql (already done) then sql/02_add_users_and_rooms.sql
2. Copy .env.example to .env and fill URL + anon key (Supabase > Project Settings > API)
3. npm install   then   npm run dev   (open http://localhost:5173)
4. Deploy: npm run build, upload the dist folder to Netlify/Vercel (add the same two env variables)
